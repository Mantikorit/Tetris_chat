# Chat Tetris 🟦

Тетрис, которым управляет твой чат на Twitch — через голосование командами или наградами за баллы канала. Подключается к [Streamer.bot](https://streamer.bot/) по WebSocket. Без сборки, без сервера: чистый Vue 3 + Canvas, работает прямо с GitHub Pages.

## Как играет чат

1. Стример нажимает **Старт** (игра не начинается сама при открытии сайта). Во время игры доступны **Пауза** (замораживает голосование и таймеры) и **Сброс игры** (возврат к чистому полю и ожиданию старта).
2. Идёт голосование: чат пишет команды (`влево`, `вправо`, `поворот`, `вниз`, `сброс` — настраивается) или использует награды за баллы канала.
3. Один зритель — один голос за раунд; новая команда заменяет предыдущую.
4. По таймеру побеждает самый частый вариант, при ничьей — случайный из лидеров. Пока идёт голосование, фигура не падает.
5. Ход применяется, фигура опускается на клетку (`вниз` — на две, `сброс` — мгновенно до конца), начинается новое голосование.
6. Уровень растёт каждые N собранных линий (по умолчанию 10, настраивается). Каждый уровень сокращает время голосования на заданный шаг (по умолчанию 1 с), но не ниже минимума (5 с — из-за задержки трансляции).
7. После game over игра автоматически перезапускается через 30 секунд — начинается новый заход для чата.

Всё помещается в один экран без прокрутки (колонки слева направо: памятка с командами для чата → счёт и панель голосования → игровое поле → последние голоса и история ходов). Длинные списки прокручиваются внутри своих панелей. Настройки открываются на весь экран.

### Кастомизация внешнего вида

Вид всех блоков настраивается переменными в начале `css/style.css` (раздел «1. Настройка внешнего вида»): фон и рамки панелей, скругление, отступы, тени, шрифты, ширина колонок, палитра и цвета действий. Файл подробно прокомментирован по разделам.

## Настройка Streamer.bot

1. В Streamer.bot откройте **Servers/Clients → WebSocket Server**.
2. Включите сервер (по умолчанию `127.0.0.1:8080`) — галочка **Auto Start** пригодится.
3. Убедитесь, что Twitch-аккаунт подключён (Platforms → Twitch), чтобы бот получал сообщения чата и награды.
4. Откройте сайт с тетрисом, при необходимости поменяйте адрес WebSocket в настройках (⚙).

Больше ничего в Streamer.bot создавать не нужно — сайт сам подписывается на события `ChatMessage` и `RewardRedemption`.

### Награды за баллы канала

В настройках сайта (⚙) укажите **точные названия** наград из Twitch для каждого действия. Голос через награду имеет повышенный вес (по умолчанию ×3, настраивается).

## Запуск локально

Достаточно открыть `index.html` в браузере. Если браузер ругается на локальные файлы — запустите любой статический сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Деплой на GitHub Pages

```bash
git init
git add .
git commit -m "Chat Tetris"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/chat-tetris.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**. Через минуту сайт будет доступен по адресу `https://ВАШ_НИК.github.io/chat-tetris/`.

### ⚠️ Важно про HTTPS и локальный WebSocket

GitHub Pages работает по HTTPS, а Streamer.bot — по незашифрованному `ws://`. Браузеры по-разному относятся к такому сочетанию:

- **Chrome / Edge** — разрешают `ws://127.0.0.1` и `ws://localhost` со страниц HTTPS. Рекомендуется использовать их.
- **Firefox / Safari** — могут блокировать подключение. Если статус висит на «Подключение…», откройте сайт локально (см. выше) или используйте Chrome.

Сайт должен быть открыт **на том же ПК**, где запущен Streamer.bot (адрес `127.0.0.1`). Если тетрис открыт на другом устройстве, укажите в настройках IP компьютера со Streamer.bot и разрешите внешние подключения в настройках WebSocket-сервера.

### Для OBS

Страницу можно добавить как **Browser Source** прямо в OBS (WebSocket на localhost там работает). Кнопку «Старт» нажимайте через «Взаимодействие» (Interact) с источником.

## Тест без чата

В настройках включите **Тест-режим**: игра стартует без подключения, а стрелки ← → ↑ ↓ и пробел (сброс) засчитываются как голоса с клавиатуры.

## Структура

```
index.html          — разметка и Vue-шаблон
css/style.css       — стили
js/tetris.js        — движок тетриса (чистая логика)
js/streamerbot.js   — WebSocket-клиент Streamer.bot
js/app.js           — Vue-приложение: голосование, таймеры, отрисовка
```

Все настройки сохраняются в `localStorage` браузера.
